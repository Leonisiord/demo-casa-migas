# Casa Migas · Demo de web para panadería de barrio

Web de demostración para una panadería recién abierta. Diseñada y programada desde cero.

**Demo en vivo:** https://carlosdev-demo005.netlify.app

> Es una demo de portfolio: el negocio y todos los datos son ficticios.

## Lo destacado
- Paleta pastel y toldo a rayas propios.
- Carta con ilustraciones hechas para la ocasión.
- Indicador de "Abierto ahora / Cerrado ahora" calculado con la hora real.
- Encargos por WhatsApp o formulario (el formulario de la demo no envía datos).

## Tecnología
HTML, CSS y JavaScript en un único `index.html`, sin dependencias. Tipografías: Caprasimo, Nunito y Caveat.
`_headers` incluye `noindex` para que los buscadores no indexen la demo.

## Desplegar
Se publica la raíz del repositorio tal cual (sin build).
